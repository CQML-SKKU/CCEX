# PyCCE reference coherences (S=1/2 electron qubit, electron-spin bath)

| file | method |
|---|---|
| `pycce_mecce.dat` | ME-CCE (conventional CCE + Lindblad bath jumps) |
| `pycce_gcce.dat` | gCCE |
| `pycce_megcce.dat` | ME-gCCE |
| `pycce_megcce_qz.dat` | ME-gCCE with a qubit S_z jump beside the bath jumps |

- The first three copied from `origin/adding_MECCE` (tip `2c63eac52`), `test/mecce_test/comparison_megcce_S05/`; md5
  of each file against the branch blob in `MD5SUMS` (checked when copied).
- Generated by the branch's `test/mecce_test/compare_megcce_S05.py` (the PyCCE version is not recorded). A numpy
  re-implementation of the PyCCE 1.1.1 algorithm reproduces the three files within 2.2e-8 (plan, appendix A).
- `pycce_megcce_qz.dat` is not the branch's: generated on 2026-10-13 with PyCCE 1.1.1 (numpy 1.26.4, scipy 1.13.1,
  pandas 2.2.3), md5 in `MD5SUMS`, as
  `atoms = pycce.random_bath('e', [5e3]*3, density=1e16, density_units='cm-3', seed=2)` (the same bath as
  `../../inputs/bath_espin`, md5 66b36814fd7e8f7b2e4e278df1719c7f), `atoms.add_single_jump('p', rate=1.0, units='rad')`,
  `atoms.add_single_jump('m', rate=1.0, units='rad')`, `c = pycce.CenterArray(spin=0.5, alpha=[1,0], beta=[0,1])`,
  `c.add_single_jump('z', rate=1.0, units='rad')`, `pycce.Simulator(spin=c, bath=atoms, order=2, r_bath=500,
  r_dipole=300, magnetic_field=300).compute(np.linspace(0,2,21), method='megcce', quantity='coherence', nbstates=0,
  pulses=1)`; written `t Re Im` without a header line, 21 rows.
- Time axis `linspace(0, 2, 21)` [ms]; format `t Re Im` (the branch's three with one `#` header line). The CCEX run uses `deltat 0.1`,
  `nstep 20`, so the last PyCCE row (t = 2) has no CCEX counterpart (`compare.py --subset-b`).
- Conjugation: PyCCE measures $\langle R\alpha\vert\rho\vert R\beta\rangle$ and CCEX $\langle\alpha\vert\rho\vert\beta\rangle$,
  which are complex conjugates after an odd number of pi pulses. gCCE and ME-gCCE are compared with `conj(PyCCE)`
  (`--conj-b`); ME-CCE is compared without it, since its values in this system have no imaginary part (below 1e-10
  on both sides), so the convention cannot be told apart there.
