# docs/

What to read, by what you are trying to do. Dated records are in git history (last row);
everything here is current.

| Folder | For | Read |
|---|---|---|
| `user/` | running CCEX | `GettingStarted.md` (build, `mpirun ... -f ccein.json`, the command-line flags, the environment variables), `InputFile.md` (the input file and its eight groups of keys, one page per group: `InputFile_General.md`, `_Qubit`, `_Cluster`, `_Backend`, `_Pulse`, `_Defect`, `_Output`, and `InputFile_AutoConvergence.md` for the `auto_convergence` block, each key with its type, unit and default; the fixed unit of every number under `#Units`), `OutputFiles.md` (every output file and its columns), `Changes.md` (a summary of the changes of 2.1.0 and 2.0.0; the full list is `CHANGELOG.md`), `Overview.md` (what the code computes and how it is organised), `Analysis.md` (the analyzer, from `example/analysis/`), `Tools.md` (the bath generator, the tensor reader, the isotope table, the input-key tools and the automatic-convergence commands, from `example/tools/`), `Examples.md` (the index of the thirteen tutorials, `00_quickstart` … `12_pseudospin`, whose own `README.md` and `expected.png` describe them since 2026-10-16; the pages `Examples_01.md` … `Examples_11.md` and `../images/tutorials/` were removed then). Converted from the Doxygen pages on 2026-09-24; the tutorials themselves are `example/tutorial/` |
| `methods/` | understanding a method | `Methods.md` (the list of the method pages), `cce.md` (cCCE and gCCE: the Hamiltonian, the expansion, the mean fields, the cCCE corrections knight/hfmedi/delta_A, the defect bath model, dsj/itb/dsjitb), `pcce.md` (partition CCE), `bundle-adaptive.md` (bundle clustering and the adaptive refinement), `gpu.md` (the CUDA backend: `backend`, the `gpu_options` block, the packed kernel, what runs on the GPU), `coordinate-frame-rotation.md` (the `frame.rotation` block: what the rotation transforms, leaves alone and refuses, and its keys), `deer.md` (DEER bath pulses: the `pulse.bath` block, which bath spins a pump drives, the merged qubit/bath sequence, what is supported and refused), `master-equation.md` (ME-CCE and ME-gCCE, `method` meCCE / megCCE with `hamiltonian.<method>.jump_operators`: the Lindblad equations in Liouville space, memory, the changes from the adding_MECCE branch, the checks, the relation to PyCCE and PRL 132, 250401) |
| `doxygen/` | the API reference | `do_doxy` (or `doxygen Doxyfile`) runs Doxygen on `include/`, `src/` (`*.cpp`, `*.h`, `*.cu`), `user/` and `methods/` (`mdfilter.sh` strips the path and page part of a `Page.md#anchor` or `../user/Page.md#anchor` link, which Doxygen cannot resolve but GitHub can, drops the directory of a `../methods/page.md` page link, and turns a link to a file outside the site into its repository path in code); the output (`html/`, `latex/`, `xml/`) is written here and not committed. The look is the doxygen-awesome theme (two `.css` files, MIT) with `ccex.css` on top; `header.html` is Doxygen's own template plus one line that loads `ccex.js`, which opens the tree entry of the page being shown |
| `images/` | figures the pages above use | |
| (records) | what was decided and measured, by date | the 86 dated records of 2026-09-11 to 2026-09-23 and the pre-branch `TODO` (87 files) were taken out of the tree on 2026-09-24; they are in git history up to commit 83fe451d5: `git show 83fe451d5:docs/archive/<name>`, `git ls-tree 83fe451d5 docs/archive/` lists them |
