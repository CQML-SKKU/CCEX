# docs/

What to read, by what you are trying to do. Dated records are in git history (last row);
everything here is current.

| Folder | For | Read |
|---|---|---|
| `user/` | running CCEX | `GettingStarted.md` (build, `mpirun ... -f ccein.json`, the command-line flags), `InputFile.md` (the input file and its seven groups of keys, one page per group: `InputFile_General.md`, `_Qubit`, `_Cluster`, `_Backend`, `_Pulse`, `_Defect`, `_Output`, and `InputFile_AutoConvergence.md` for the `auto_convergence` block, each key with its type, unit and default), `Overview.md` (what the code computes and how it is organised), `Analysis.md` (the analyzer and the convergence test, from `example/analysis/`), `Tools.md` (the bath generator, the tensor reader and the job runner, from `example/tools/`), `Examples.md` (the twelve tutorials, one page each: `Examples_01.md` … `Examples_12.md`, with the figures in `../images/tutorials/`). Converted from the Doxygen pages on 2026-09-24; the tutorials themselves are `example/tutorial/` |
| `methods/` | understanding a method this branch added | `clustering-terminology.md` (site / bundle / cluster / partition; bundle clustering vs adaptive refinement), `adaptive-cluster-mode.md` (bundle clustering: `cluster_mode=bundle`, `bundle.max_dim`, with or without `rdip`), `adaptive-input-block.md` (the `adaptive` block that turns on the refinement, and its keys), `gpu.md` (the CUDA backend: `backend`, the `gpu_options` block, the packed kernel, what runs on the GPU), `coordinate-frame-rotation.md` (the `coordinate_frame_rotation` block: what the rotation transforms, leaves alone and refuses, and its keys), `deer.md` (DEER bath pulses: the `pulse.bath` block, which bath spins a pump drives, the merged qubit/bath sequence, what is supported and refused) |
| `doxygen/` | the API reference | `do_doxy` (or `doxygen Doxyfile`) runs Doxygen on `include/`, `src/` (`*.cpp`, `*.h`, `*.cu`), `user/` and `methods/` (`mdfilter.sh` strips the path and page part of a `Page.md#anchor` or `../user/Page.md#anchor` link, which Doxygen cannot resolve but GitHub can, drops the directory of a `../methods/page.md` page link, and turns a link to a file outside the site into its repository path in code); the output (`html/`, `latex/`, `xml/`) is written here and not committed. The look is the doxygen-awesome theme (two `.css` files, MIT) with `ccex.css` on top; `header.html` is Doxygen's own template plus one line that loads `ccex.js`, which opens the tree entry of the page being shown |
